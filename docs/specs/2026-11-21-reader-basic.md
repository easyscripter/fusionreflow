# Читаем EPUB (5.A): спека

**Задача плана:** 5.A «Читаем EPUB» — первый срез блока 5 «Читалка» (план 2): части 5.2 и 5.3, разрыв строк пока
движком Flutter
**Стек:** оба (Rust: функция моста; Flutter: пакет рендера, экран чтения)
**Ветка:** `feat/reader-basic` — одна ветка и один PR; сначала `rust-developer` (мост), затем `flutter-developer`
в той же ветке. Ревьюеры смотрят свою часть диффа.
**Статус:** утверждена человеком 2026-11-21.

## Цель

Книга из библиотеки открывается по «Продолжить / Начать чтение» и читается постранично: листание сдвигом и тапами
по краям, место чтения сохраняется и восстанавливается, поворот экрана открывает тот же фрагмент. Заглушка
`ReaderPlaceholderScreen` уходит.

## Решения человека (2026-11-21)

1. **Нарезка — сквозной срез, потом улучшения** (таблица выше). В 5.A текст идёт без видимых переносов:
   спайк 0а показал, что движок Flutter рвёт строку на `U+00AD` без дефиса.
2. **Мост — зеркало модели.** Новая функция `book_content(bytes) -> Book`; Dart-классы блоков генерирует
   flutter_rust_bridge через `#[frb(mirror(...))]`, как уже сделано для `FormatError`. Формат блоков v1,
   `FORMAT_VERSION` и эталон `book_v1.cbor` не меняются. Новых зависимостей нет.
3. **Номера внизу страницы — страница в главе и процент:** «Глава 3 из 27 · 5 из 18 · 34%». Сквозная нумерация
   «14 из 412» — в 5.C.
4. **Системные панели Android скрыты** на экране чтения (immersive sticky): свайп от края показывает их на время,
   системный «назад» работает.
5. **Листание — сдвиг** (страница уезжает за пальцем); тапы по краям листают с той же анимацией. Шейдер — план 3.
6. **Рисуются все блоки v1, включая настоящие таблицы** сеткой с колонками.
7. **Код по CSS-классу (2026-11-21, дефект QA, исправлен до ревью).** EPUB, где код размечен абзацами и `span` с
   классом моноширинного шрифта, а не `<pre>`/`<code>`, импортируется с `Block::Code` и стилем `code`
   (`rust/flow-core/src/import/epub/css.rs`). Упрощённый разбор: без каскада и специфичности, составные и вложенные
   селекторы не учитываются; не работает внутри таблиц и `figure`; моноширинный абзац со ссылкой или картинкой
   остаётся обычным абзацем; жирное внутри строки кода теряется. Лимиты: стиль ≤ 1 МиБ, ≤ 16 стилей на главу,
   ≤ 64 на книгу, ≤ 1024 класса в одном стиле; битый или слишком большой стиль пропускается, импорт не падает.
   Версия конвертера поднята.
8. **Пробелы «= =», «! =» в книге не исправляются:** они стоят в исходном файле.
9. **Телефон в альбомной** раскладывается по таблице «Стиль страницы» по ширине окна (пункт 4 «Расхождений» не
   действует).

## Интерфейсы

### Rust: мост (`rust/bridge/src/api/book.rs`)

```rust
/// Decodes CBOR `bytes` and returns the whole book for the reader.
/// Errors: the `flow_core::decode` error as is.
pub fn book_content(bytes: Vec<u8>) -> Result<Book, FormatError>;
```
- `Book`, `Meta`, `TocEntry`, `BlockNode`, `Block`, `ListMarker`, `Table`, `SourceRef`, `Inline`, `Style`,
  `Script`, `LinkTarget`, `ResourceId`, `Resource` — `pub use flow_core::…` + `#[frb(mirror(...))]`-описания, как
  у `FormatError`. Логики в мосте нет. Если зеркало рекурсивного `Block` (`Quote`/`Footnote` с `Vec<BlockNode>`)
  не генерируется, разработчик останавливается и спрашивает человека (не меняет модель сам).
- Тесты в том же модуле: `book_content_reads_fixture` (из `book_v1.cbor`: `meta`, число блоков, оглавление,
  ресурсы равны `flow_core::decode` того же файла), `book_content_rejects_garbage`, `book_content_rejects_empty`.

### Flutter: пакет `packages/flow_render/`

Подключается в `pubspec.yaml` приложения как `flow_render: {path: packages/flow_render}` (не внешняя зависимость).
Зависимости пакета — только `flutter` и (dev) `flutter_test`, `very_good_analysis` той же версии, что у приложения.
Riverpod в пакете нет.

Две библиотеки (ViewModel импортирует только первую):
- `package:flow_render/flow_render.dart` — модель, стиль, разбивка (без `widgets.dart`);
- `package:flow_render/widgets.dart` — виджет страницы.

**Модель (`lib/src/model/`):** неизменяемые классы с `==`/`hashCode` (без freezed: пакет без кодогенерации —
*решение аналитика*).

```dart
class FlowBook { String title; List<FlowSection> sections; }        // sections не пустой (см. «Главы»)
class FlowSection { String? title; List<FlowBlock> blocks; int get length; } // length = сумма длин блоков

sealed class FlowBlock { int get length; }
class FlowText extends FlowBlock {      // абзац, заголовок, пункт списка, строка кода, сноска, подпись
  FlowTextRole role; int headingLevel /*1..6, для heading*/; int indent /*0..*/; String? marker;
  List<FlowSpan> spans;                 // length = сумма длин span
}
enum FlowTextRole { body, heading, code, footnote, caption }
class FlowImage extends FlowBlock { Uint8List bytes; }                 // length = 1
class FlowTable extends FlowBlock { List<List<List<FlowSpan>>> rows; } // length = сумма (длина ячейки + 1)
class FlowRule extends FlowBlock {}                                     // разделитель, length = 1

sealed class FlowSpan { int get length; }
class FlowTextSpan extends FlowSpan {   // length = text.length (UTF-16, U+00AD считается)
  String text; bool bold; bool italic; bool code; bool link; FlowScript script;
}
class FlowImageSpan extends FlowSpan { Uint8List bytes; double heightEm; } // length = 1
enum FlowScript { normal, sup, sub }
```

**Смещение (offset)** — индекс в UTF-16 в «тексте главы»: конкатенации длин её блоков по порядку. Блок картинки,
разделитель и картинка внутри строки занимают 1. `U+00AD` входит в смещения всегда, рисуется он или нет. Так
позиция не зависит ни от размера экрана, ни от будущих настроек переносов.

**Стиль (`lib/src/style/flow_style.dart`):**
```dart
class FlowStyle {
  String fontFamily; String codeFontFamily; double fontSize; double lineHeight /*множитель*/;
  EdgeInsets padding /*поля текста внутри страницы*/; bool justify;
  Color textColor; Color mutedColor; Color accentColor;

```

**Разбивка (`lib/src/layout/`):**
```dart
abstract interface class LineBreaker {           // 5.B добавит свою реализацию
  List<FlowLine> breakLines(FlowText block, double width, FlowStyle style);
}
class EngineLineBreaker implements LineBreaker { const EngineLineBreaker(); } // 5.A: строки движка TextPainter

class FlowLine { int start; int end; double height; /* + данные для отрисовки, на усмотрение разработчика */ }

class FlowPaginator {
  const FlowPaginator({LineBreaker lineBreaker = const EngineLineBreaker()});
  /// Pages of [section] for a page of [size]. Never empty: an empty section gives one empty page.

}
class FlowPage {

  List<FlowPageItem> items;    // что и где рисовать; состав — на усмотрение разработчика
```

декодирования).

**Виджет (`lib/src/widgets/flow_page_view.dart`):** `FlowPageView({required FlowPage page, required FlowStyle style})`
— рисует одну страницу (текст главы без колонтитулов) в `CustomPaint`; размер — тот, что передавался в `paginate`.

#### Правила вёрстки в 5.A
- **Строки текста** — `EngineLineBreaker`: абзац раскладывается `TextPainter` целиком, строки берутся из
  `computeLineMetrics` / `getLineBoundary`, на странице рисуется только её диапазон строк (обрезка по строкам).
  Перед раскладкой `U+00AD` заменяется на `U+2060` (WORD JOINER, длина та же, смещения 1:1, разрыва нет).
  Golden-тест проверяет, что на месте `U+2060` нет видимого знака; если знак виден — разработчик удаляет `U+00AD`
  с таблицей пересчёта смещений и пишет об этом в PR (*решение аналитика*).
- **Абзац** (`body`): отступ первой строки 1.3 em, выравнивание по ширине (`justify`), последняя строка — по
  левому краю (так делает движок).
- **Заголовок**: Literata 600, размер `fontSize × {1: 1.25, 2: 1.15, 3+: 1.05}`, по центру, отступ сверху 1 строка,
  снизу 0.8 строки (у первого блока страницы верхний отступ не ставится). Заголовок не бывает последним на
  странице: если после него не помещается ни одной строки следующего блока, он уходит на следующую страницу.
- **Пункт списка**: маркер «•» или «N.» в висячем отступе, `indent` — уровень вложенности, 1.5 em на уровень.
- **Цитата**: блоки цитаты с `indent + 1`; глубже 4 уровней отступ не растёт.
- **Код**: JetBrains Mono, `fontSize × 0.85`, по левому краю, без отступа первой строки, длинная строка
  переносится движком. Каждая строка `Block::Code` — отдельный `FlowText(role: code)`.
- **Сноска** (`Block::Footnote`): в том месте, куда её положил импорт; `fontSize × 0.85`, цвет `mutedColor`.
- **Ссылка**: цвет `accentColor`, не нажимается. Ссылка на сноску (`NoteRef`) — её `label` как `sup` цветом
  `accentColor`.
- **Верхний / нижний индекс**: `fontSize × 0.75` и `FontFeature.superscripts()` / `subscripts()`; точный сдвиг
  базовой линии — 5.B.
- **Жирный**: Literata — вариативный шрифт (`fvar`), жирность задаётся и `fontWeight`, и
  `fontVariations: [FontVariation('wght', 700)]`; golden-тест показывает, что жирный отличим.
- **Картинка** (`Figure`, `Formula`, `FixedPage`, `Inline::Image`): блок вписывается в ширину и высоту страницы с
  сохранением пропорций, не увеличивается больше исходного размера в логических пикселях; подпись (`caption`) —
  отдельный блок `FlowText(role: caption)` по центру, `fontSize × 0.85`. Если картинка не влезает в остаток
  страницы, она переносится на следующую. Битые байты картинки — рамка высотой 3 строки цвета `mutedColor`, без
  исключения. Картинка в строке — `PlaceholderSpan` высотой `heightEm × fontSize`.
- **Таблица**: сетка с линиями толщиной 1 цветом `mutedColor`, текст ячеек `fontSize × 0.9`, по левому краю.
  Ширина колонок: пропорционально наибольшей ширине содержимого колонки в одну строку, но не меньше самого длинного
  слова колонки; если минимальные ширины не влезают — колонки поровну, слова рвутся движком. Таблица делится между
  страницами по строкам таблицы. Строка таблицы выше страницы раскладывается как ячейки друг под другом (каждая —
  абзац), чтобы текст не потерялся.
- **Висячие строки**: у абзаца из ≥ 2 строк на странице не остаётся одна первая строка внизу и не уходит одна
  последняя строка наверх следующей; абзац из 2 строк, не влезающий целиком, переносится целиком. Если правило
  невыполнимо (страница вмещает одну строку) — правило не применяется.
- **Слово шире строки** (Review Focus 3): движок рвёт его посимвольно; текст не обрезается и не выходит за поля.
- **Разделитель**: линия 1/3 ширины по центру, отступы по 1 строке.
- Межблочный интервал абзацев — 0 (абзацы различаются отступом), остальные блоки — 0.5 строки сверху и снизу.

### Flutter: приложение

**Главы (`lib/data/services/flow_book_mapper.dart`, чистые функции):**
```dart
FlowBook flowBookOf(rust_book.Book book);
```
- Начала глав — индексы `TocEntry.block` всех уровней, отсортированные, без повторов и без выходящих за
  `book.blocks`; добавляется 0, если его нет. Глава — блоки от начала до следующего начала.
- Заголовок главы — `title` последней по порядку записи оглавления с этим блоком (у «Часть первая» и «Глава 1» на
  одном блоке — «Глава 1»); до первой записи — `null`.
- Оглавления нет → начала глав — блоки `Heading` уровня 1–2; заголовок — текст заголовка без `U+00AD`.
- Нет и таких заголовков → главы по 200 блоков верхнего уровня, заголовок `null` (*решение аналитика*: ленивая
  разбивка не должна раскладывать огромную книгу целиком).
- Пустая книга (`blocks` пуст) → одна пустая глава.
- Перевод блоков: `Paragraph → FlowText(body)`, `Heading → FlowText(heading, level)`, `ListItem → FlowText(body,
  marker, indent: depth)`, `Quote → блоки с indent + 1`, `Code → FlowText(code)` на строку, `Footnote → блоки с
  role footnote`, `Figure → FlowImage + FlowText(caption)` (подпись — если не пуста), `Formula`/`FixedPage →
  FlowImage`, `Table → FlowTable`, `Separator → FlowRule`; `Inline::Text → FlowTextSpan`, `Link → span с link`,
  `NoteRef → FlowTextSpan(label, sup, link)`, `Inline::Image → FlowImageSpan`. Ресурс, на который нет `Resource`,
  → пустые байты (рисуется рамкой битой картинки).

**Сервис и репозиторий:**
```dart
// RustCoreService
Future<FlowBook> bookContent(Uint8List bytes);   // rust_book.bookContent + flowBookOf
// BookRepository
Future<FlowBook> open(String id);                // load(id) + bookContent; BookNotFoundException как у load;
                                                  // FormatError моста → BookFormatException
```

**Позиция.** Смысл `ReadingPosition` (оставляет 5.2, теперь фиксируется): `chapter` — индекс главы в
`FlowBook.sections`, `offset` — смещение в тексте главы (см. выше). Сохраняется смещение **первого символа
текущей страницы**. Позиция вне книги (глава ≥ числа глав, смещение > длины главы, отрицательные) прижимается:
глава — к последней, смещение — к `[0, length]`. Схема БД не меняется.

**Прогресс** для `savePosition`: `(сумма длин глав до chapter + offset) / длина книги`; книга нулевой длины → 0.
Значение в `0..1`.

**ViewModel `lib/ui/reader/view_models/reader_view_model.dart`:** `@riverpod class ReaderViewModel` (family по
`bookId`), `AsyncNotifier<ReaderState>`; импортирует `package:flow_render/flow_render.dart`, не `widgets.dart`.
```dart
@freezed abstract class ReaderState {   // lib/ui/reader/view_models/reader_state.dart
  FlowBook book; ReadingPosition position; Size? viewport; FlowStyle? style;
  /* загруженные страницы глав (текущая ± 1) и номер текущей страницы — на усмотрение разработчика */
}
// методы
Future<void> setViewport(Size size, FlowStyle style); // первый вызов и каждый поворот/изменение окна:
                                                      // перекладка глав ± 1, страница по position
Future<void> showPage(int delta);   // листание на delta (±1) с переходом через границу главы
// геттеры для экрана: текущая/соседние страницы, chapterTitle, chapterIndex, chapterCount,
// pageInChapter (с 1), pagesInChapter, percent = (progress × 100).floor() — та же формула, что
// progressPercent в библиотеке, но без потолка 99: на последней странице книги 100
```
- Раскладываются только текущая глава и соседние; ушедшие дальше выгружаются (*решение аналитика*).
- Смена страницы → `savePosition(bookId, position, progress)` сразу после того, как страница встала. Ошибка
  записи не мешает читать: состояние отдаёт событие ошибки, экран показывает SnackBar «Не удалось сохранить место
  чтения»; `BookNotFoundException` при записи (книгу удалили) — без SnackBar.
- Первая страница книги — листание назад ничего не делает; последняя — вперёд ничего не делает.
- `setViewport`, вызванный снова, пока идёт предыдущая перекладка, — результат старой отбрасывается.

**Экран `lib/ui/reader/widgets/reader_screen.dart` (`ReaderScreen`)** — заменяет `ReaderPlaceholderScreen` на

## Review Focus

- **Огромная книга / огромная глава:** раскладывается только глава ± 1; глава из одного абзаца на 1 МБ текста —
  время `paginate` и отсутствие ANR (замер в отчёте QA).
- **Кривое оглавление:** повторы, обратный порядок, ссылки за пределы `blocks` — главы всё равно корректны.
- **Позиция из старой версии / другой раскладки:** `(0, 0)` по умолчанию, вне книги — прижимается, не падает.
- **Поворот и split-screen посреди перекладки:** старый результат не перезаписывает новый.
- **Уход с экрана во время записи позиции** и удаление книги, пока она открыта, — без падения.
- **Битые ресурсы:** картинка без `Resource`, не PNG/JPEG, нулевой длины.
- **Таблица шире страницы и с пустыми ячейками; пустой абзац; глава из одной картинки.**
- **`U+2060` вместо `U+00AD`:** нет видимых знаков, смещения не сдвинуты.
- **Направления импортов:** мост — только из `data/services`; ViewModel — без `flow_render/widgets.dart`.

## Решения, принятые на гриллинге

| Вопрос | Решение | Почему |
|---|---|---|
| Нарезка блока 5 | 5.A срез → 5.B разрыв строк → 5.C панель (человек) | читать можно после первой задачи |
| Как книга попадает в Dart | `book_content` + зеркала FRB (человек) | один декодер, без новых зависимостей |
| Номера страниц | страница в главе + процент (человек) | сквозная нумерация требует раскладки всей книги |
| Системные панели | скрыты, immersive sticky (человек) | больше места под текст |
| Листание | сдвиг, шейдер — план 3 (человек) | не задерживать «можно читать» |
| Какие блоки | все, таблицы сеткой (человек) | книги с таблицами читаются без дыр |
| Что такое глава | начала — записи оглавления всех уровней; без оглавления — `Heading` 1–2; иначе по 200 блоков (*решение аналитика*) | позиция и ленивая разбивка опираются только на книгу |
| Смысл `ReadingPosition` | глава + UTF-16 смещение в тексте главы, первая буква страницы (*решение аналитика*) | не зависит от размера экрана и настроек |
| Где модель рендера | в пакете `flow_render`, перевод из моста — `data/services` (*решение аналитика*) | мост только в `data/services`; пакет без приложения |
| Переносы в 5.A | `U+00AD` → `U+2060` (*решение аналитика*) | без разрыва без дефиса, смещения 1:1 |
| Размеры страницы | константы по макетам до 6.1 (*решение аналитика*) | настроек ещё нет |
| Тап в центре | ничего в 5.A (*решение аналитика*) | панель — 5.C; выход — системный «назад» |
