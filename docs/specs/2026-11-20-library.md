# Библиотека с импортом: спека

**Задача плана:** 3.2 «Библиотека» вместе с 4.3 «Экран импорта и прогресса». Задачи объединены решением человека
2026-11-20: библиотека сразу умеет добавлять книги.
**Стек:** Flutter (+ Kotlin в `MainActivity`: канал выбора файла)
**Ветка:** `feat/library`
**Статус:** утверждена человеком 2026-11-20 (круг 2, все рекомендации приняты).

## Цель

Вкладка «Библиотека» показывает книги из хранилища (3.1) по макету: обложка-заглушка, название, автор, прогресс,
блок «Продолжить чтение», сортировка, пустое состояние. Кнопка «Добавить» открывает выбор файла, показывает
прогресс конвертации с отменой, кладёт книгу в библиотеку и открывает её. Тап по книге открывает заглушку
читалки на сохранённой позиции.

## Решения человека (2026-11-20, круг 2)

Человек принял все четыре рекомендации:
1. **Выбор файла — свой канал на Kotlin (вариант А).** `MethodChannel("app.fusionreflow/documents")` в
   `MainActivity`: `pick` (`ACTION_OPEN_DOCUMENT`, `*/*`) → `{uri, name, size}`, `openFd(uri)` →
   `detachFd()`. Новых зависимостей нет, мост не меняется. `file_picker` отклонён: он копирует файл в кэш и отдаёт
   путь, а мост принимает только дескриптор.
2. **Без листа «Файл / Папка».** «Добавить» сразу открывает системный выбор файла. Импорт папки, ссылки на
   исходники и «копии в настройках» — отдельная задача.
3. **Готовая книга открывается сразу**, как в плане. SnackBar «“…” добавлена · Открыть» — задача импорта папки.
4. **«Не хватает места» с цифрами — в задаче 7.** Здесь ошибка записи при `add` показывает «Не удалось открыть
   файл».

Остальные ответы первого круга (решения человека 2026-11-20): debug-фикстур нет; обложки — заглушка по макету;
в «Продолжить чтение» — автор и процент; поиска нет; меню ⋮ только в debug и только ради спайка переносов;
маршрут `/reader/:bookId` с заглушкой читалки согласован.

**Следствие для QA.** Без фикстур и до слияния конвертера EPUB (4.1) любой формат отвечает «не поддерживается», и
на устройстве библиотеку с книгами не увидеть. Полная библиотека, «Продолжить чтение» и сортировки проверяются
виджет- и golden-тестами на фейках. На Pixel 7 эти сценарии прогоняются, только если 4.1 уже слит в `main`
(тогда ветку обновляют от `main`). Иначе в отчёте QA их помечают «ждёт 4.1».

## Границы

В задаче:
- экран «Библиотека» по макетам `library`, `library-small`, `library-tablet`, `library-wide`, `library-empty`
  (светлая и тёмная темы, телефон и планшет): блок «Продолжить чтение», сетка книг, обложка-заглушка, подпись
  прогресса и формата, счётчик, сортировка «Недавние / Название / Автор», пустое состояние, загрузка и ошибка;
- импорт одного файла: выбор (EPUB, FB2, `.fb2.zip`, PDF), карточка конвертации в сетке с прогрессом и
  «Отменить» (`library-importing2`), `BookRepository.add`, открытие книги;
- карточки результата по `states` и `import-pdf-later`: «PDF будет доступен позже», «Этот формат не
  поддерживается», «Не удалось открыть файл», «Нет доступа к файлу», «Добавление отменено»;
- маршрут и экран-заглушка читалки;
- кнопка спайка переносов — в debug-меню ⋮;
- строки ru/en в ARB, юнит-, виджет- и golden-тесты.

Не в задаче (и где это делается):
- конвертер EPUB — 4.1 (идёт параллельно в Rust-сессии и подключается без изменений здесь), FB2 — 4.2;
- импорт папки, экран выбора книг из папки, ссылки на исходники — отдельная задача (решение человека 2);
- полноэкранный прогресс конвертации PDF с этапами, «Свернуть», уведомление (`import-progress`) — план 3, вместе
  с настоящим конвертером PDF;
- несколько импортов одновременно, очередь — не делается (*решение аналитика*: в плане нужен один файл);
- долгое нажатие, удаление, карточка книги — 3.3;
- настоящие обложки — отдельная задача после 4.1/4.2;
- глава и страницы в «Продолжить чтение» — 5.x;
- поиск — не делается (решение человека);
- «Не хватает места» с цифрами — 7 (решение человека 4);
- запоминание сортировки между запусками — 6.x (*решение аналитика*: нужно хранилище настроек);
- настоящая читалка и `savePosition` — 5.x.

Порядок задач в `FusionReflow-Plan-2.md` (4.3 вливается в 3.2) обновляет родительская сессия или человек, не
эта задача.

## Интерфейсы

Существующее, что задача потребляет: `BookRepository.watchAll()` и `add(bytes, format)` (3.1; `add` по хешу
источника возвращает уже существующую книгу), `BookEntry`, `ReadingPosition`, `BookFormat`, `BookFormatException`,
мост `importBook({fd, kind})` → `Stream<ImportEvent>` (`Started(jobId)`, `Progress(stage, done, total)`,
`Done(bytes)`, `Failed(ImportError)`) и `cancelImport({jobId})`, `windowSizeClassOf`, `AppDimens`, тема, `pumpApp`,
`FakeRustCoreService`.
**Не меняются:** API моста, схема БД, `BookRepository`, формат блоков.

### Домен — `lib/domain/models/`

`library_sort.dart`:
```dart
/// Порядок книг в библиотеке.
enum LibrarySort { recent, title, author }

/// Книги в порядке [sort]; исходный список не меняется.
List<BookEntry> sortBooks(Iterable<BookEntry> books, LibrarySort sort);
```
Правила (*решение аналитика*): `recent` — по убыванию `lastReadAt ?? addedAt`. `title` — по возрастанию без учёта
регистра, `ё` приравнивается к `е`: в `intl` нет сравнения по локали, а по кодам «ё» встаёт после «я». Латиница
идёт перед кириллицей. `author` — по первому автору с теми же правилами, книги без автора в конце; при равных
первых авторах сравнивается название. При равенстве всех ключей порядок задаёт `id`.

`reading_status.dart`:
```dart
enum ReadingStatus { fresh, reading, finished }

extension BookReadingStatus on BookEntry {
  /// fresh: lastReadAt == null && progress == 0; finished: progress >= 1; иначе reading.
  ReadingStatus get readingStatus;
  /// floor(progress * 100), зажат в 0..99 для reading (99,6% не показывается как 100%).
  int get progressPercent;
}
```

`import_source.dart` (freezed):
```dart
/// Файл, выбранный для импорта.
@freezed
abstract class ImportSource with _$ImportSource {
  const factory({
    required String uri,        // content:// от системного выбора
    required String name,       // имя файла для показа
    BookFormat? format,         // по расширению; null — формат не поддерживается
    int? sizeBytes,
  }) = _ImportSource;
}
```
Формат определяется по расширению имени без учёта регистра: `.epub`, `.fb2`, `.fb2.zip` (проверяется раньше
`.zip`), `.pdf`. Остальное, включая просто `.zip`, даёт `null`. Функция `BookFormat? bookFormatOfFileName(String
name)` лежит в этом же файле.

`import_update.dart` (freezed, sealed) — что происходит с импортом, без типов моста:
```dart
@freezed
sealed class ImportUpdate with _$ImportUpdate {
  const factory ImportUpdate.progress({required int done, required int total}) = ImportProgress;
  const factory ImportUpdate.converted(Uint8List bytes) = ImportConverted;
  const factory ImportUpdate.failed(ImportFailure failure) = ImportFailed;
}

/// Причина неудачи; у каждой своя карточка по макету `states`.
enum ImportFailure { pdfNotYet, unsupportedFormat, unreadable, noAccess, cancelled }
```

### Данные

`lib/data/services/document_picker_service.dart` — обёртка над каналом `app.fusionreflow/documents` (решение человека 1), без состояния:
```dart
class DocumentPickerService {
  /// Системный выбор файла; null — пользователь закрыл выбор.
  Future<({String uri, String name, int? size})?> pick();
  /// Новый дескриптор для чтения [uri]; владение переходит к вызывающему (мосту).
  /// Бросает PlatformException, если файла нет или доступ отозван.
  Future<int> openFd(String uri);
}
@Riverpod(keepAlive: true) DocumentPickerService documentPickerService(Ref ref);
```
Kotlin: `MainActivity` регистрирует канал. `pick` — `ACTION_OPEN_DOCUMENT`, `CATEGORY_OPENABLE`, тип `*/*`
(у FB2 на Android часто нет MIME-типа). Имя и размер берутся из `OpenableColumns`. `openFd` —
`openFileDescriptor(uri, "r")?.detachFd()`. Ошибки отдаются как `PlatformException`.

`RustCoreService` — два новых метода-обёртки (доступ к Rust только через этот сервис):
```dart
Stream<rust_import.ImportEvent> importBook(int fd, BookFormat format);   // BookFormat → SourceKind
Future<void> cancelImport(int jobId);
```

`lib/data/repositories/import_repository.dart`:
```dart
abstract interface class ImportRepository {
  /// Системный выбор файла; null — выбор закрыт без файла.
  Future<ImportSource?> pick();

  /// Конвертирует [source]: ноль или больше progress, затем ровно одно converted или failed, и поток
  /// закрывается. format == null → сразу failed(unsupportedFormat), мост не вызывается.
  /// openFd бросил → failed(noAccess).
  Stream<ImportUpdate> convert(ImportSource source);

  /// Отменяет текущую конвертацию. Если Started ещё не пришёл, отмена запоминается и уходит в мост сразу
  /// после Started. Без текущей конвертации ничего не делает.
  Future<void> cancel();
}
class BridgeImportRepository implements ImportRepository { new({required DocumentPickerService picker, required RustCoreService rust}); }
@Riverpod(keepAlive: true) ImportRepository importRepository(Ref ref);
```
Перевод ошибок моста: `Unsupported(pdf)` → `pdfNotYet`; `Unsupported(другой)` → `unsupportedFormat`;
`Corrupted`, `NoTextLayer`, `OutOfMemory` → `unreadable`; `Cancelled` → `cancelled`. Ошибка самого потока моста
(`FrbException`) тоже даёт `unreadable`: поток не обрывается без финального события.

### ViewModel

`lib/ui/library/view_models/library_state.dart` и `library_view_model.dart`:
```dart
@freezed
abstract class LibraryState with _$LibraryState {
  const factory({
    required List<BookEntry> books,   // сетка: все книги, кроме continueReading, в порядке sort
    required int totalCount,          // все живые книги (счётчик «8 книг»)
    required LibrarySort sort,
    BookEntry? continueReading,       // книга с наибольшим lastReadAt, кроме finished
  }) = _LibraryState;
}

@riverpod
class LibraryViewModel extends _$LibraryViewModel {
  Stream<LibraryState> build();       // поверх bookRepository.watchAll(), по умолчанию recent
  void setSort(LibrarySort sort);     // пересобирает state без нового watchAll
}
```
Книга из «Продолжить чтение» в сетку не попадает, как в макете телефона. Ошибка `watchAll` даёт `AsyncError`,
а «Повторить» делает `ref.invalidate`.

`lib/ui/import/view_models/import_state.dart` и `import_view_model.dart`:
```dart
@freezed
sealed class ImportState with _$ImportState {
  const factory ImportState.idle() = ImportIdle;
  const factory ImportState.running({required ImportSource source, int? done, int? total}) = ImportRunning;
  const factory ImportState.failed({required ImportSource source, required ImportFailure failure}) = ImportFailedState;
  const factory ImportState.added({required String bookId}) = ImportAdded;   // View открывает книгу и зовёт acknowledge
}

@Riverpod(keepAlive: true)   // импорт не прерывается при переходе на другую вкладку
class ImportViewModel extends _$ImportViewModel {
  ImportState build();                 // idle
  Future<void> pickAndImport();        // выбор → running → converted → bookRepository.add → added
  Future<void> cancel();               // в running; итог — failed(cancelled), книга не добавляется
  Future<void> retry();                // из failed: тот же source, новый fd (openFd)
  void dismiss();                      // failed → idle
  void acknowledge();                  // added → idle
}
```
Правила:
- `pickAndImport` в состоянии `running` ничего не делает, а View показывает SnackBar «Дождитесь окончания
  добавления книги». Одновременно идёт один импорт.
- Пользователь закрыл выбор без файла (`pick` → null) — остаёмся в `idle`, без сообщений.
- Отмена главнее результата: если после `cancel` пришло `converted` (гонка с завершением в Rust), `add` не
  вызывается, итог — `failed(cancelled)`.
- `add` бросил `BookFormatException` или ошибку записи — итог `failed(unreadable)`.
- Повторный импорт того же файла: `add` возвращает существующую запись, итог `added(id существующей)`. Дубля нет,
  открывается та же книга.

`lib/ui/reader/view_models/reader_placeholder_view_model.dart`: `@riverpod Stream<BookEntry?>
readerPlaceholderViewModel(Ref ref, String bookId)` — книга из `watchAll()` по id или `null`.

Карточки результата (`ImportFailure` → макет):

| Причина | Заголовок | Текст | Кнопки |
|---|---|---|---|
| `pdfNotYet` | PDF будет доступен позже | Конвертация PDF в книгу появится в одном из следующих обновлений. EPUB и FB2 уже открываются и читаются. Ниже — имя файла и «PDF · {size} · в библиотеку не добавлен» (без размера, если он неизвестен) | «Выбрать EPUB или FB2» → `dismiss` + `pickAndImport`; «Понятно» → `dismiss` |
| `unsupportedFormat` | Этот формат не поддерживается | Приложение читает EPUB, FB2 и FB2.ZIP. PDF появится позже, DOCX и MOBI можно перевести в EPUB. | «Понятно» |
| `unreadable` | Не удалось открыть файл | Файл повреждён или скачан не до конца. Скачайте его заново и добавьте ещё раз. | «Выбрать другой файл» → `dismiss` + `pickAndImport` |
| `noAccess` | Нет доступа к файлу | Файл перенесён или удалён. Выберите его заново. | «Выбрать файл» → `dismiss` + `pickAndImport` |
| `cancelled` | Добавление отменено | Книга не сохранена. Её можно добавить снова. | «Повторить» → `retry`; «Закрыть» → `dismiss` |

Тексты `noAccess` и `cancelled` короче макета (*решение аналитика*). В макете «…чтобы пересобрать книгу и открыть
оригинал» и «незаконченная конвертация удалена» — это функции хранения ссылок на исходники и фоновой
конвертации, которых в задаче нет.

`lib/ui/core/theme/app_cover_palette.dart`: цвета обложек из макета (`#6B1F2A`, `#26457A`, `#3A3F5C`, `#2E5E4E`,
`#5B4A8A` и до 8 оттенков той же насыщенности). `forBook(sourceHash)` берёт индекс по первым двум hex-символам,
`forName(fileName)` — по сумме кодов символов (у импортируемой книги хеша ещё нет). Белый текст на каждом цвете
даёт контраст не ниже 4.5. Пустое название (`Meta.title == ""`; конвертер EPUB 4.1 пишет так книгу без названия) показывается как
«Без названия» (`libraryUntitled`) везде, где выводится название: на обложке, в карточке, в «Продолжить чтение» и в
заглушке читалки, пустые авторы не выводятся, несколько
авторов соединяются через «, ».

- `AppRoutes.reader = '/reader/:bookId'`, `static String readerOf(String bookId)`. Маршрут верхнего уровня вне

## Review Focus

- Владение дескриптором: fd, полученный от `openFd`, уходит в мост ровно один раз. Если мост не вызван (ошибка до
  вызова), fd не теряется: `openFd` вызывается непосредственно перед `importBook`, между ними нет кода, который
  может бросить.
- Отмена: до `Started`, во время `Progress`, одновременно с `Done`; двойной тап «Отменить»; отмена после того, как
  импорт уже закончился. Ни в одном случае книга не добавляется после `cancel` и нет исключений.
- Поток моста закрылся без финального события или упал — состояние не зависает в `running`.
- Огромный файл (сотни МБ): ничего не читается в память Dart, байты идут только из Rust в `add`.
- Выбранный файл удалили между выбором и «Повторить» — `noAccess`, а не падение.
- Огромная библиотека: ленивая сетка, сортировка только при новых данных или смене сортировки.
- Кривые данные каталога: пустое название и авторы, `progress` вне `0..1` — подписи не падают.
- Книга удалена, пока открыта заглушка читалки, — «Книга не найдена» без исключения.
- Системный шрифт 200%: карточки и карточки ошибок не переполняются.
- Release: нет ⋮, все строки из ARB.
